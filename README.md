# C++ Tactical Combat Simulator

A turn-based tactical combat simulator written in C++ demonstrating state management, struct parameters passed by reference, and randomized hit mechanics.

## ⚔️ Key Features
- **Turn-Based Battle Loop:** Interactive combat system supporting player actions and automated enemy counter-attacks.
- **Pass-By-Reference Architecture:** Efficient struct parameter passing (`Entity&`) to manipulate health and stats without unnecessary copy overhead.
- **Action Selection & RNG:** Dynamic move selection including standard strikes, high-variance critical attacks, and healing spells.
